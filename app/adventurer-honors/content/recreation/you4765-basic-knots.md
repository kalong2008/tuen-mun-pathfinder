## 要求

1. 知道並能解釋不同型式的繩結。
2. 學習打下列的繩結，能解釋他們的用處：
   a. 雙套結
   b. 滑結
   c. 漁夫結
   d. 繩環
   e. 雙套結
   f. 平結
   g. 繫帆結
   h. 稱人結
   i. 珍珠結
   j. 醫生結
   k. 瓶口結
   l. 八字結
3. 把你所學到的 12 種繩結的打法，做成一個模型貼在木板或紙版上。

## 答案

榮譽證目的：認識繩結類型與用途，學會手冊所列繩結並做成展示板，強調「選對結、打緊、檢查」。

帶領建議：每人一段練習繩；職員先做慢動作示範；可二人互查。Wikibooks 無對應頁。手冊 a 與 e 皆列「雙套結」——確認是否同一結或變體後按導師教材示範。

### 要求 1

解釋繩結類型概念：止索結、連接結、繫泊結、環結等。重點：用途要對、打緊、留足夠繩尾；錯誤鬆脫可能危險。

帶領提示：用「這種情況用哪類結？」情境題。

### 要求 2

逐一練習並說用途（名稱以手冊為準，可對照常用英文名）：

| 手冊名 | 常見用途提示 |
| --- | --- |
| 雙套結 | 快速繫柱／臨時固定 |
| 滑結 | 可調鬆緊的環 |
| 漁夫結 | 連接兩繩（尤釣魚線） |
| 繩環 | 繩端做環 |
| 平結 | 連接同粗細繩（非承重救命） |
| 繫帆結 | 繫帆／綁角 |
| 稱人結 | 安全環，救援常用 |
| 珍珠結 | 裝飾／固定珠狀 |
| 醫生結 | 外科／綁紮相關（依教材） |
| 瓶口結 | 提瓶／綁頸 |
| 八字結 | 止索、防繩端抽出 |

帶領提示：每結「示範→跟打→說用途→打緊檢查」；稱人結務必由職員核對正確。

安全注意：勿用練習結承載人體重量作遊戲；正式用途另受訓。

### 要求 3

將約 12 種繩結樣品固定在木板／厚紙板，旁註名稱與用途，作展覽與複習。

材料：繩段、木板／卡紙、膠水／釘、標籤

帶領提示：統一排列美觀；可在家庭夜展示。
